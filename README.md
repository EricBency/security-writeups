# Security Write-ups

Write-ups from labs and challenges I've completed while learning ethical hacking and penetration testing. Each one covers the goal, my approach, what went wrong, and how the vulnerability can be fixed. All testing was done on legal, authorized lab environments (PortSwigger Web Security Academy, TryHackMe, HackTheBox) — no real-world systems were tested without permission.

I'm currently self-studying penetration testing — networking, web application security. Related tools and scripts are in [pentest-tools](https://github.com/EricBency/pentest-tools).

The repo is organized into folders by platform: `portswigger/` for PortSwigger Web Security Academy labs, `tryhackme/` for TryHackMe rooms, and `htb/` for HackTheBox machines.
